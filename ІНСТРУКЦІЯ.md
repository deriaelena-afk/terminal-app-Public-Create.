# TERMINAL — розгортання сайту

У цій папці — готовий сайт (`index.html`, `manifest.json`, дві іконки). Лишилось 3 кроки: підключити базу даних, викласти на GitHub, додати на головний екран.

## Крок 1 — Supabase (база даних + вхід в акаунт)

1. Зайдіть на **supabase.com** → Sign up (можна через Google) → **New project**.
   - Назва проєкту: будь-яка, наприклад `terminal`
   - Пароль бази даних: згенеруйте і збережіть кудись (на майбутнє, самим користуватись не доведеться)
   - Регіон: European (найближчий до України)
2. Зачекайте ~2 хвилини, поки проєкт створиться.
3. У лівому меню відкрийте **SQL Editor** → **New query** і вставте це:

```sql
create table app_state (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null,
  updated_at timestamptz default now()
);

alter table app_state enable row level security;

create policy "Users manage own data"
  on app_state
  for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
```

Натисніть **Run**. Це створює одну таблицю, де кожен користувач бачить лише свій рядок.

4. У лівому меню → **Settings** → **API**. Скопіюйте:
   - **Project URL** (виглядає як `https://xxxxx.supabase.co`)
   - **anon public** ключ (довгий рядок, це не секрет — він призначений для використання в браузері)

5. Відкрийте `index.html` у будь-якому текстовому редакторі (навіть Блокнот підійде), знайдіть рядки:
```js
const SUPABASE_URL = "YOUR_SUPABASE_URL";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
```
і вставте туди свої значення. Збережіть файл.

**Важливо:** за замовчуванням Supabase вимагає підтвердження email при реєстрації. Якщо хочете спростити (без листа-підтвердження) — у Supabase зайдіть в **Authentication → Providers → Email** і вимкніть "Confirm email".

## Крок 2 — GitHub Pages (безкоштовний хостинг)

1. Зайдіть на **github.com** → створіть акаунт, якщо ще немає.
2. Натисніть **New repository**, назвіть, наприклад, `terminal-app`, зробіть **Public**, створіть.
3. На сторінці репозиторію → **Add file → Upload files** → перетягніть усі 4 файли з цієї папки (`index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`) → **Commit changes**.
4. У репозиторії: **Settings → Pages** → у розділі "Build and deployment" оберіть **Deploy from a branch**, гілка `main`, папка `/ (root)` → **Save**.
5. Через хвилину-дві там з'явиться посилання виду `https://ваш-нікнейм.github.io/terminal-app/` — це ваш сайт.

## Крок 3 — Додати на головний екран

**На айфоні:** відкрийте посилання в **Safari** → кнопка "Поділитися" (квадрат зі стрілкою) → **На екран "Домівка"**.

**На ноутбуці (Chrome/Edge):** відкрийте посилання → у адресному рядку праворуч з'явиться іконка встановлення (⊕ або комп'ютер зі стрілкою) → **Встановити**.

Після цього іконка TERMINAL з'явиться і на телефоні, і на ноутбуці — відкриватиметься як окремий застосунок, без адресного рядка браузера.

## Як це працює далі

- Перший вхід — реєструєтесь email + паролем прямо в застосунку.
- На іншому пристрої — заходите тим самим email + паролем, і одразу бачите тих самих клієнтів і задачі.
- Дані зберігаються в Supabase (реальна база даних), а не в браузері — тому нічого не загубиться при очищенні кешу.
